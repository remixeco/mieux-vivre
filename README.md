# Mieux vivre

Prototype de soutien quotidien en santé mentale, disponible en version iPhone et web.

- iPhone : ouvrir `MieuxVivre/MieuxVivre.xcodeproj` dans Xcode. Voir [les instructions](MieuxVivre/LISEZ-MOI.md).
- Web : servir le dossier `MieuxVivre/Web` localement.
- Vérification : `node MieuxVivre/checks.cjs`.
