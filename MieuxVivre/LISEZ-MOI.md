# Mieux vivre sur iPhone

Le projet Xcode contient une seule application. Le carnet réunit l’humeur, les activités choisies et la récupération. Les programmes et le catalogue d’exercices au poids du corps s’ouvrent hors ligne.

Ouvre `MieuxVivre.xcodeproj` depuis le dossier `iphone` de ce dépôt. Xcode prépare les ressources du carnet à chaque compilation. Choisis un simulateur iPhone et lance l’application avec **⌘R**. Sur un iPhone physique, utilise la même équipe de signature que pour l’ancienne installation de **Mieux vivre**.

Avant de mettre à jour **Mieux vivre**, exporte une sauvegarde de l’ancienne version. Le projet garde l’identifiant `com.remi.mieuxvivre` et le point d’entrée local de l’ancienne version. Garde l’ancienne version installée jusqu’à la mise à jour, puis vérifie que tes saisies sont encore visibles. Restaure l’export si nécessaire.

Pour transférer les séances déjà notées dans **À mon rythme**, exporte le JSON depuis cette application et enregistre-le dans **Fichiers**. Ouvre ensuite **Historique → Sauvegarde activité** dans **Mieux vivre** pour l’importer. Vérifie que tes anciennes journées apparaissent avant de retirer l’ancienne application. La restauration de l’humeur est aussi disponible depuis **Historique**.

L’envoi vers Apple Santé conserve la fonction **humeur quotidienne**, sur les appareils compatibles à partir d’iOS 18. Il exige une action et une autorisation de ta part.
